# Tejus Kumar Verma – Portfolio

React + TypeScript + Vite.

## Run locally
    npm install
    npm run dev        # http://localhost:5173

## Production build
    npm run build      # outputs dist/
    npm run preview

## Personalise
- Photo: save as `public/photo.jpg` (4:5 portrait works best).
- Resume: replace `public/resume.pdf`.
- LinkedIn / GitHub: edit `LINKS` in `src/data.ts`.
- Project links: add `github` / `live` to a project in `src/data.ts`.

## Deploy
Vercel or Netlify: import the GitHub repo, build command `npm run build`, output directory `dist`.
